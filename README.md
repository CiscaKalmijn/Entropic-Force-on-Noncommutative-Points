Entropic Force on Noncommutative Points

In this reposity there is a script used to make one of the illustrations in the paper "Entropy of Noncommutive Spaces" (yet to be published).
The file Entropic-force-on-points.py contains a script studying the evolution of distances between noncommutative points under the entropic force as derived in the aforementioned paper. Besides, for a collection of three distances it contains a script that places these points into the real plane, which allows us to draw the evolution of three points under the force.
